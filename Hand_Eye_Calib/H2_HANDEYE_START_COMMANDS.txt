2. 终端 B：同一台 H2，上臂随机可达位姿
------------------------------------------------

另开一个终端：

ssh unitree@192.168.1.3

# 不要 source ros2。上臂直接发 rt/arm_sdk。
# 先用遥控器进入 AI 模式并站稳。
export PYTHONPATH=/home/unitree/MscapeTech/unitree_sdk2_python:$PYTHONPATH
# 网卡不对时把 --iface eth0 换成 ifconfig 里连机载网的那块

cd /home/unitree/MscapeTech/Hand_Eye_Calib

python3 random_upper_arm_sweep.py \
  --backend sdk \
  --mode dwell \
  --count 0 \
  --dwell-s 2 \
  --confirm-robot-motion \
  --iface eth0 \
  --wrist-payload-kg 0.75 \
  --web-url http://127.0.0.1:8081

# 启动后先把右臂抬到胸前平举（肩 pitch -55°，肘约 40°，右腕 roll -90°），再在附近小范围随机。
# 默认开 URDF 重力前馈（tau≠0），右腕按夹爪+相机 0.75 kg。
# 终端应出现 [SDK] 重力补偿已开 ... wrist_payload=0.75kg。不要加 --no-gravity。
# 控臂改到网页按钮，不要再盯这个终端按 W/A/S。
# 臂还在动时网页按钮保持灰色；停稳后变可点：
#   下一个 n     这个点用完了（网页已 Save），抽下一个，计入
#   再抽 s      看不见棋盘，另抽一个，不计入
#   结束 q      结束并回到平举
#   X± Y± Z±    末端平移，躯干系。X/Y 默认 2 mm，Z+ 默认 20 mm 向上抬。到位后脚本会持续发 rt/arm_sdk，否则手臂会垂下
#   R± P± Y±    末端旋转，默认 2°
#   步长 /2 ×2  XY 和 Z 步长一起缩放（XY 下限 2 mm，Z 下限 5 mm）
#   跟随实测    以当前关节 FK 为下一次微调原点
# 终端里仍可按 n/s/q 应急。--count 0 表示一直抽到按结束。

4. 现场顺序
------------------------------------------------

1) WSL 跑完第 0 节，目标必须是 unitree@192.168.1.3
2) 遥控器切 AI 并站稳
3) 开终端 A（带上面的 PYTHONPATH），浏览器打开 http://192.168.1.3:8081
4) 网页确认是腕部相机；不是就点 Next Camera
5) 开终端 B，不要开 ROS，直接跑 sweep
6) 棋盘钉死，只动右臂；每点停 2 秒，有绿角点再 Save，然后点网页「下一个」
7) 大约 20–30 个有效 Save 后，在终端 A 跑第 3 节宽松求解（只要朝向）；PBVS 才用严格门禁
